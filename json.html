The path is parse → binary request → validated relay → compiled modification → binary reply → JSON output. This demo stays in your browser; an application supplies its own network transport.

Compact transport omits per-message schema hashes and frame lengths. Both peers must agree on the exact argument/result schemas and transport version before using it. Portable transport identifies the schema in every message.

Compiled calls materialize target values. This demonstrates portable binary interoperability, without claiming zero-copy execution or a measured speedup.
